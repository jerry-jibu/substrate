# credprovider

## Overview

API group for the credential-provider plugin API. The `v1` directory holds the
`substrate.credprovider.v1` proto package and its generated Go bindings.

## Subdirectories & Boundaries

- v1: [./v1/EGM.md](./v1/EGM.md) - the `CredentialProvider` service with its
  single `FetchSecret` RPC.
