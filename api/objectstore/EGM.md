# objectstore

## Overview

API group for the object-store plugin API. The `v1` directory holds the
`substrate.objectstore.v1` proto package and its generated Go bindings.

## Subdirectories & Boundaries

- v1: [./v1/EGM.md](./v1/EGM.md) - the `NodeProvider`, `ControlProvider`,
  and `AssetProvider` services for snapshot transfer and sandbox assets.
