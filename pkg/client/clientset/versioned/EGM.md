# clientset/versioned

## Overview
The versioned clientset for Substrate's CRD types, generated by `client-gen` (`clientset.go` carries `Code generated ... DO NOT EDIT`). It bundles the `ate/v1` typed clients with a discovery client behind one `Interface`.

## Interface
- `Interface` with `Discovery()` and `AteV1()` (`clientset.go:Interface`)
- `Clientset` implementing `Interface`, embedding `discovery.DiscoveryClient` (`clientset.go:Clientset`)
- Constructors: `NewForConfig`, `NewForConfigAndClient`, `NewForConfigOrDie`, `New` (`clientset.go:NewForConfig`, `clientset.go:NewForConfigAndClient`, `clientset.go:NewForConfigOrDie`, `clientset.go:New`)
- Subdirectory contracts: [./typed/EGM.md](./typed/EGM.md), [./scheme/EGM.md](./scheme/EGM.md), [./fake/EGM.md](./fake/EGM.md)

## Invariants
- All typed clients share one HTTP transport built from the config (`clientset.go:NewForConfig` comment and implementation).
- When `RateLimiter` is unset and QPS is set, Burst must be greater than 0 (`clientset.go:NewForConfigAndClient` error path).
- `NewForConfigOrDie` panics on config errors (`clientset.go:NewForConfigOrDie`).

## Side Effects
- Every method reaches the Kubernetes API server over HTTP; the clientset sets a default user agent and an optional token-bucket rate limiter (`clientset.go:NewForConfig`, `clientset.go:NewForConfigAndClient`).
