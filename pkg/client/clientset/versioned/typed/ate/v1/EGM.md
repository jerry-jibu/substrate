# clientset/versioned/typed/ate/v1

## Overview
Typed REST clients for the `ate` group, version `v1`, generated by `client-gen` from the CRD types in `api/infra/k8s/ate/v1` (all files carry `Code generated ... DO NOT EDIT`). Covers `CSIDriverConfig` (cluster-scoped), `SandboxConfig` (cluster-scoped), and `WorkerPool` (namespaced).

## Interface
- `AteV1Interface` with `RESTClient()`, plus the `CSIDriverConfigsGetter`, `SandboxConfigsGetter`, and `WorkerPoolsGetter` interfaces (`ate_client.go:AteV1Interface`)
- `AteV1Client` with constructors `NewForConfig`, `NewForConfigAndClient`, `NewForConfigOrDie`, `New`, and accessor methods `CSIDriverConfigs()`, `SandboxConfigs()`, `WorkerPools(namespace)` (`ate_client.go:AteV1Client`)
- `CSIDriverConfigInterface`: `Create`, `Update`, `Delete`, `DeleteCollection`, `Get`, `List`, `Watch`, `Patch` (`csidriverconfig.go:CSIDriverConfigInterface`)
- `SandboxConfigInterface`: same verb set (`sandboxconfig.go:SandboxConfigInterface`)
- `WorkerPoolInterface`: same verb set plus `UpdateStatus` (`workerpool.go:WorkerPoolInterface`)
- Expansion marker interfaces: `CSIDriverConfigExpansion`, `SandboxConfigExpansion`, `WorkerPoolExpansion` (`generated_expansion.go`)
- Subdirectory contract: fake: [./fake/EGM.md](./fake/EGM.md)

## Invariants
- `setConfigDefaults` pins the client to `atev1.SchemeGroupVersion` and API path `/apis` (`ate_client.go:setConfigDefaults`).
- `NewForConfigOrDie` panics on config errors (`ate_client.go:NewForConfigOrDie`).

## Side Effects
- All CRUD methods issue HTTP requests against the Kubernetes API server through the shared `rest.Interface` (`ate_client.go:AteV1Client` via `gentype.ClientWithList` in `workerpool.go:newWorkerPools`).
