# informers/externalversions/ate

## Overview
Group-level access to the shared informers of the `ate` API group. Generated by `informer-gen`. Its single file `interface.go` exposes the group's versions.

## Interface
- `Interface` with `V1() v1.Interface` (`interface.go:Interface`)
- `New(f, namespace, tweakListOptions)` builds the group interface from a factory (`interface.go:New`)
- Subdirectory contract: v1: [./v1/EGM.md](./v1/EGM.md)

## Invariants
- The group carries the factory, namespace, and `TweakListOptionsFunc` handed to `New`; every version informer created below inherits them (`interface.go:group`).

## Side Effects
- None in this package; informers it returns start goroutines through the factory (see [./v1/EGM.md](./v1/EGM.md)).

## Verification
- Run: `go test ./pkg/client/informers/externalversions/ate/...` from the repo root.
