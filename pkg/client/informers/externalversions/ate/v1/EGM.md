# informers/externalversions/ate/v1

## Overview
Per-resource shared informers for the `ate` group, version `v1`, generated by `informer-gen` (every file carries `Code generated ... DO NOT EDIT`). Each informer wraps the versioned clientset's list/watch calls in a `cache.SharedIndexInformer` and exposes a lister over its indexer. Covers `CSIDriverConfig`, `SandboxConfig`, and `WorkerPool`.

## Interface
- `Interface` with `CSIDriverConfigs()`, `SandboxConfigs()`, and `WorkerPools()` returning the typed informers (`interface.go:Interface`)
- `TypedWorkerPoolInformer` / `WorkerPoolInformer` with `Informer()`, `TypedInformer()`, and `Lister()`; constructors `NewWorkerPoolInformer`, `NewTypedWorkerPoolInformer`, `NewFilteredWorkerPoolInformer`, `NewTypedFilteredWorkerPoolInformer`, `NewWorkerPoolInformerWithOptions`, `NewTypedWorkerPoolInformerWithOptions`; adapters `ToTypedWorkerPoolInformer` and `ToWorkerPoolIndexInformer` (`workerpool.go:TypedWorkerPoolInformer`, `workerpool.go:NewWorkerPoolInformer`, `workerpool.go:NewTypedWorkerPoolInformerWithOptions`)
- `TypedCSIDriverConfigInformer` / `CSIDriverConfigInformer` with the same constructor family (`csidriverconfig.go:TypedCSIDriverConfigInformer`, `csidriverconfig.go:CSIDriverConfigInformer`)
- Typed handler and indexer aliases per resource, e.g. `WorkerPoolHandlerFuncs`, `WorkerPoolIndexers`, `DeletedWorkerPool` (`workerpool.go:WorkerPoolHandlerFuncs`)

## Invariants
- `ToTypedWorkerPoolInformer` and `ToWorkerPoolIndexInformer` are only safe when the informer handles `*WorkerPool` objects; otherwise the type-safe methods panic (`workerpool.go:ToTypedWorkerPoolInformer` doc comment).
- Prefer factory-obtained shared informers over the standalone `New*Informer` constructors, to cut memory and API connections (`workerpool.go:NewWorkerPoolInformer` doc comment).
- The `WorkerPool` informer is namespaced; `CSIDriverConfig` and `SandboxConfig` informers are cluster-scoped (`interface.go` version struct wiring, `workerpool.go:workerPoolInformer`).

## Side Effects
- `Informer()`/`TypedInformer()` registered on the factory starts background list/watch goroutines when the factory starts (`workerpool.go:defaultInformer` wires `client.AteV1().WorkerPools(namespace).List/Watch` into `cache.ListWatch`).
