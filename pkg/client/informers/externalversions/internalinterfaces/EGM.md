# informers/externalversions/internalinterfaces

## Overview
Shared interface definitions the generated informer packages use to avoid an import cycle between the factory and the per-group informers. Generated by `informer-gen`; the single file `factory_interfaces.go` carries a `Code generated ... DO NOT EDIT` header.

## Interface
- `NewInformerFunc func(versioned.Interface, time.Duration) cache.SharedIndexInformer` (`factory_interfaces.go:NewInformerFunc`)
- `SharedInformerFactory` with `Start`, `InformerFor`, and `InformerName` (`factory_interfaces.go:SharedInformerFactory`)
- `TweakListOptionsFunc func(*v1.ListOptions)` (`factory_interfaces.go:TweakListOptionsFunc`)
- `InformerOptions` with `ResyncPeriod`, `Indexers`, `InformerName`, and `TweakListOptions` fields (`factory_interfaces.go:InformerOptions`)

## Invariants
- An unset `InformerOptions.ResyncPeriod` defaults to 0, meaning no resync (`factory_interfaces.go:InformerOptions` field doc).
- `InformerName` must be created via `cache.NewInformerName()` at startup, which validates global uniqueness (`factory_interfaces.go:InformerOptions` field doc).

## Side Effects
- None (interface and option types only).
