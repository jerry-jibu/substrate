# informers/externalversions

## Overview
The shared informer factory for Substrate's CRD types, generated by `informer-gen` (`factory.go` and `generic.go` carry `Code generated ... DO NOT EDIT`). It caches one `cache.SharedIndexInformer` per object type so controllers share watches and caches.

## Interface
- `SharedInformerFactory` with `Start`, `StartWithContext`, `Shutdown`, `WaitForCacheSync`, `WaitForCacheSyncWithContext`, `ForResource`, `InformerFor`, and `Ate()` (`factory.go:SharedInformerFactory`)
- Constructors: `NewSharedInformerFactory`, the deprecated `NewFilteredSharedInformerFactory`, and `NewSharedInformerFactoryWithOptions` (`factory.go:NewSharedInformerFactory`, `factory.go:NewFilteredSharedInformerFactory`, `factory.go:NewSharedInformerFactoryWithOptions`)
- Options: `WithCustomResyncConfig`, `WithTweakListOptions`, `WithNamespace`, `WithTransform`, `WithInformerName` (`factory.go:WithCustomResyncConfig` through `factory.go:WithInformerName`)
- `GenericInformer` with `Informer()` and `Lister()`, and `(*sharedInformerFactory).ForResource` dispatching `csidriverconfigs`, `sandboxconfigs`, and `workerpools` (`generic.go:GenericInformer`, `generic.go:ForResource`)
- Subdirectory contracts: [./ate/EGM.md](./ate/EGM.md), [./internalinterfaces/EGM.md](./internalinterfaces/EGM.md)

## Invariants
- `InformerFor` returns the same `SharedIndexInformer` instance for a given object type across calls (`factory.go:InformerFor`).
- After `Shutdown`, no new informers start and `Start` returns without doing anything; `Shutdown` blocks until all informer goroutines stop (`factory.go:Shutdown` doc comment).
- `Start`/`StartWithContext` do not block and race with a later `WaitForCacheSync` (`factory.go:Start` doc comment).
- `WithInformerName` requires a name from `cache.NewInformerName()`; each informer type registers its GVR under it (`factory.go:WithInformerName` doc comment).

## Side Effects
- `StartWithContext` runs each registered informer in a goroutine tracked by the factory's `WaitGroup` (`factory.go:StartWithContext`).
- Informers issue list and watch requests against the API server through the versioned clientset (`factory.go:InformerFor` passes `f.client` to `newFunc`).
