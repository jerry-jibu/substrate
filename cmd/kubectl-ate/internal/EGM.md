# kubectl-ate/internal

## Overview
Internal packages of the `kubectl-ate` plugin binary: the cobra command tree and the output printers.

## Subdirectories & Boundaries
- cmd: [./cmd/EGM.md](./cmd/EGM.md) - verb and resource commands, admin key management, proxy.
- printer: [./printer/EGM.md](./printer/EGM.md) - table/json/yaml renderers for ateapi resources.
