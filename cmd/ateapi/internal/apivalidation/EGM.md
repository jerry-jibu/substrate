# ateapi/internal/apivalidation

## Overview

Request and field validation for the ateapi Control and WorkerService RPCs,
generated by Kubernetes validation-gen plus hand-written custom rules
(`doc.go` codegen directives).

## Interface

- `ValidateCreate/Get/List/Update/Delete*Request` per resource (`actor.go`, `actor_template.go`, `atespace.go`, `tag.go`, `worker.go`, `egress_policy.go`, `access_policy.go`) - request-shape validation for actors, templates, atespaces, tags, workers, egress policies, and access policies.
- Actor lifecycle request validators (`actor.go`): `ValidateResumeActorRequest`, `ValidateSuspendActorRequest`, `ValidateRevertActorRequest`, `ValidateMintActorJWTRequest`, `ValidateMintWorkerActorCertificateRequest`, `ValidateMintWorkerActorJwtRequest`.
- Worker RPC validators (`worker.go`): `ValidateRegisterWorkerRequest`, `ValidateDrainWorkerRequest`, `ValidateAcquireWorkerEpochRequest`, `ValidateSetWorkerSandboxRuntimesRequest`, `ValidateRequestActorSuspendRequest`, `ValidateReportActorCrashedRequest`, `ValidateMarkWorkerAvailableRequest`, `ValidateMarkWorkerUnavailableRequest`, `ValidateReportActorSnapshotStateRequest`, `ValidateListWorkerActorAssignmentsRequest`.
- `ValidateCustom_*` hooks - hand-written field rules, e.g. `ValidateCustom_Container_Image` and `ValidateCustom_SnapshotConfig_StorageLocation` (`actor_template.go`), `ValidateCustom_EgressPolicy_Rules` with hostname/header/credential rules (`egress_policy.go`), `ValidateCustom_ResourceMetadata` (`common.go`).
- `MakeCreateOp`, `MakeUpdateOp` (`common.go`) - operation context for immutable-field checks; update validators like `ValidateActorUpdate`, `ValidateWorkerUpdate`, `ValidateTagUpdate` enforce them.
- `zz_generated.validation.go` - the generated dispatch over `api/ateapi/v1` types (input configured in `doc.go`).

## Invariants

- Update requests validate immutable fields against the prior object through the ops built by `MakeCreateOp` / `MakeUpdateOp` (`common.go`, `ValidateActorUpdate`).
- Generated rules come from the proto comments in `api/ateapi/v1`; `doc.go` pins `+k8s:validation-gen=TypesWithSuffix=Request` and the deep-equal func, so regenerating requires that input module.
