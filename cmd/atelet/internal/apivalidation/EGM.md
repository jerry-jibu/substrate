# apivalidation

## Overview

Declarative validation for the atelet RPC surface. The per-type validators are
generated by Kubernetes validation-gen from `internal/proto/ateletpb`
(`zz_generated.validation.go`); hand-written wrappers and custom field rules
live in `validate.go` and `workloadspec.go`, delegating shared field rules to
`internal/resources`.

## Interface

- `validate.go:ValidateRunRequest`, `ValidateTerminateRequest`, `ValidateCheckpointRequest`, `ValidateRestoreRequest`, `ValidateRequestActorSuspendRequest`, `ValidateReportActorCrashedRequest`, `ValidateGetActorEgressPolicyRequest`, `ValidateMintActorCertificateRequest`, `ValidatePromoteSnapshotRequest`, `ValidateDetachActorRequest`, `ValidateSetWorkerSandboxRuntimesRequest`, `ValidateRegisterWorkerRequest` - run the generated validation for each atelet RPC request type.
- `workloadspec.go:ValidateCustom_WorkloadSpec` - rejects container volume mounts naming a volume the spec does not declare.
- `workloadspec.go:ValidateCustom_Container_Image`, `ValidateCustom_EnvVar_Name`, `ValidateCustom_VolumeMount_MountPath`, `ValidateCustom_Container_VolumeMounts`, `ValidateCustom_Capabilities_Add`, `ValidateCustom_Capabilities_Drop`, `ValidateCustom_HttpGetAction_Path`, `ValidateCustom_ExternalVolumeSource_*`, `ValidateCustom_ImageVolumeSource_Reference`, `ValidateCustom_ActorMetadataItem_Path`, `ValidateCustom_TrustBundleDataSource_Path`, `ValidateCustom_SystemInfoVolumeSource_DataSources` - custom field rules delegating to `internal/resources`.
- `validate.go:ValidateCustom_EgressGateway_Address`, `ValidateCustom_ActorSandboxRuntime_SandboxClass`, `ValidateCustom_WorkerSandboxClass_SandboxClass`, `ValidateCustom_ObjectStorage_SnapshotUri` - custom rules for atelet-only fields.
- `zz_generated.validation.go:Validate_*` - generated per-type validators (validation-gen output, DO NOT EDIT).
- `doc.go` - package docs carrying the `+k8s:validation-gen` directives (`TypesWithSuffix=Request`, input `internal/proto/ateletpb`).

## Invariants

- Every request wrapper validates with `operation.Create` and returns a `field.ErrorList` without mutating the request (`validate.go:ValidateRunRequest` et al.).
- Field rules are shared with the control plane through `internal/resources`; a value failing here already passed them at template creation, so a failure is an internal inconsistency, not a user error (`workloadspec.go` package comment).
- A dangling volume mount is refused at the RPC edge, before atelet has reset the actor's directories and mounted external volumes (`workloadspec.go:ValidateCustom_WorkloadSpec`).
- `ValidateCustom_SystemInfoVolumeSource_DataSources` allows at most one `actor_metadata` entry and requires unique projected file paths, because atelet writes them in order into one tree and a repeated path silently clobbers the earlier file (`workloadspec.go`).
- Snapshot URIs must parse with `resources.ParseSnapshotURI` (`validate.go:validateSnapshotURI`).
- The generated file must not be hand-edited; it is regenerated from the proto tags (`zz_generated.validation.go` header).

## Side Effects

- None. Pure validation over request messages.
