# assets

## Overview

Static assets of the Hugo documentation site: project SCSS, browser JS,
and site icons. No direct files; everything lives in the subdirectories.

## Subdirectories & Boundaries

- js: [./js/EGM.md](./js/EGM.md) - browser scripts: glossary hover cards, code tabs with click-to-copy, offline search, home-page animation.
- scss: `site/assets/scss/_variables_project.scss` and `_styles_project.scss` - Docsy theme overrides (no contract; styling only).
- icons: `site/assets/icons/logo.png`, `cncf.svg` - site imagery (no contract; binary assets).
