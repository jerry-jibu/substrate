# site

The Hugo documentation website. Content stubs are generated from the
Markdown under `docs/` and `demos/*/README.md` by `tools/site-content`, and
release metadata comes from `tools/site-release-data`. The site has its own
`go.mod` for its build-time adapters.

## Subdirectories & Boundaries

- [./assets/EGM.md](./assets/EGM.md) - the site's SCSS, browser JS (glossary hover cards, code tabs), and icons.
- `adapters/`, `layouts/`, `static/` - Hugo templates and static files; template behavior is verified through the template tests, not per-directory contracts (non-Go template code, pruned).
- `testdata/` - fixture site used by `hack/test-site-templates.sh`; test-only, no contract.

## Invariants

- Generated content under `site/content/` is not edited by hand; it is regenerated by `tools/site-content` (`tools/site-content/EGM.md`).

## Side Effects

- Building the site needs Hugo extended and the site's npm packages (`hack/test-site-templates.sh` header).

## System Verification

- Run: `./hack/test-site-templates.sh` (builds against `site/testdata/` and checks template rendering). The site's JS has no standalone test runner.
